Batching removes repeated update statements

Illustrative SQL · explanatory example
UPDATE product        SET stock = CASE          WHEN product.id = ? THEN ?          WHEN product.id = ? THEN ?          ELSE product.stock        END        WHERE product.id IN (?, ?)
Shape

Group compatible consecutive updates, preserve command order, and keep a typed ELSE column.

PoC discovery

Bare quoted CASE columns confused the translator. Table-qualified columns restored PostgreSQL batching.
