Architecture / 14

Decisions for the next implementation

01

Productize source hydration

Require full re-indexing, visibility-aware cache invalidation, byte budgets and counted fallbacks.

02

Review independent core fixes

Key decoding, replica write routing, stock assignment, binary binding and batching semantics each have focused evidence.

03

Set the PostgreSQL support scope

Resolve the remaining 90 PostgreSQL-only failures, write budgets and platform coverage before a support decision.
